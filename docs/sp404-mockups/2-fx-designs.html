SP-404 MK2 · one design per effect

Every effect at the real size of a bus module in layout D, now widened to 340 × 520. Everything works: drag the white handles in the views, the knobs (drag up and down, Shift for fine), the buttons and the drop-downs. Values come from the effect tables in the old TouchOSC controller, so the value lists are real; the response curves are illustrative drawings, not measurements of the SP-404. One effect shows a module with its design notes; All 46 shows every module for side-by-side review. Preview bus changes the accent colour and flags effects that a bus can't load.
