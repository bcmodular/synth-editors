TB-3 editor: three layout options

These are mid-fidelity sketches drawn at 1600×940, for a single large window in a hardware-inspired style: a dark body, LED-orange highlights and amber value readouts. Every option keeps an always-visible top strip with sync, the 16-slot grid, morph and the panel controls. The values shown are made up. The controls themselves (envelope graphs, LFO sum, cross-mod matrix, mixer strips) are shared ideas that I'll refine section by section once you pick a layout.

A · Signal flow

Good
  • Reads like the synth itself: oscillators, filter, amp, distortion, then effects, left to right.
  • Every section is visible at once, with no clicks to reach anything.
  • The LFO sits under the voice row, and its three depths line up with VCO, VCF and VCA.
Awkward
  • The most crowded option, so each control gets medium size.
  • EFX panels change shape with the effect type, which can leave empty space in the bottom row.

B · Overview + focus

Good
  • The selected section gets a large editor, with room for big, precise envelope and LFO graphs.
  • The overview cards still show each section's state (mini graphs, on/off, effect type).
  • The calmest screen of the three.
Awkward
  • You can't adjust two sections side by side, for example filter env while the LFO depth plays.
  • An extra click (or a scroll in the overview) to change section.

C · Channel strips

Good
  • A mixing-desk feel: tall vertical faders give long throws and fine control with the mouse.
  • Each section is one column, so it scans quickly and the order is fixed.
  • Visualisations sit at the top of each strip.
Awkward
  • Graphs are narrow: an ADSR at ~190px wide is usable but small.
  • The matrix and EFX slot layouts have to squeeze into columns.
