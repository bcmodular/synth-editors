Layout A: section-by-section variants

Each section offers 2–3 control variants. Everything orange is live: drag to change, Shift-drag for fine control, double-click to reset, and the scroll wheel steps by one. The LFO and envelope graphs redraw as you edit. Pick one variant per section, or mix them. Faders follow your note: short and fat, about 22px tall and 140px long horizontally, about 26px wide and 100px tall vertically.

1VCO mixer

1a · vertical, LED cap
Each source has one fat vertical fader. Click the LED above it to switch the source on or off. While it's off, the fader dims but keeps its level.
1b · horizontal rows
Each source is a row: LED switch, name, then the level bar. More compact, and it lines up with the tuning rows below.

2Tuning

2a · three bipolar bars
Each bar fills from the centre line.
2b · shared ruler
One axis, with a draggable marker per oscillator, so you can see the detune between SAW, SQR and RING+SIN at a glance. The range is −127 to +24 because the parameter is asymmetric (max 151, centre 127).

3Cross mod and ring mod

3a · matrix
Rows are sources and columns are destinations. Each cell is a bipolar bar: drag left or right, double-click to zero.
3b · matrix + patch view
The same cells, plus a small patch diagram. Line thickness shows the amount, orange is positive and cyan is negative. You read it at a glance and edit in the cells.
3c · ring mod rows
The ring mod gets the same row style as mixer 1b: five source depths plus the master depth.

4Envelopes (VCF and VCA)

4a · drag the graph
Drag the corner points: the attack peak moves horizontally only, the decay/sustain point moves both ways (decay time and sustain level), and the release end moves horizontally. Values sit underneath, and you can scroll over a value to step it.
4b · graph + 4 faders
A read-only graph with four fat vertical faders beneath, aligned to the stages. Less direct, but every value has a big target.

5LFO

5a · sum + wave faders
The summed output waveform, with the five wave levels as short vertical faders right beside it. Delay shows as a fade-in ramp at the start.
5b · layered
Each component wave is drawn faintly at its level with the sum on top, and each wave's fader sits beside its own small trace. Shows where the shape comes from, but it's busier.

6Distortion type

6a · grouped picker
All 25 types are visible, grouped by family (this grouping is my reading of the names). One click to switch.
6b · stepper
A name display with ‹ › to step through the types, scroll to step, and click to open the grouped list as a popover. Saves space in the main row.

7EFX panel

7a · type buttons + slots
The type row is always visible. Mode buttons become a segmented control. Slots follow the efx.ts positions as a 2-column grid, with holes kept as gaps. Slots greyed out by BPM sync (disabledBy) dim.
7b · stepper type
The type uses the same stepper as distortion 6b, which frees the vertical space for the slots.

8Parameter assign

8a · learn-by-click
Click a target (XY MOD, PAD X, PAD Y, EFFECT), then click any parameter label in the editor to assign it. Assigned parameters carry a small tag. Esc cancels.
8b · dropdowns
Four searchable dropdowns listing every assignable parameter. Plain, but works without hunting around the screen.
